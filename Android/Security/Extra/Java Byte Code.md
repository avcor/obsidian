Java byte code is set of instruction executed by JVM 

## 1. Compilation 
- You write code in `Main.java` and compile it. Then compiler compile  it to make `Main.class` containing byte code. 
## 2. Distribution 
- `.class` file can be used any OS 
## 3. Execution 
- Local JVM reads byte code  and translate to machine code using an Interpreter or (JIT)
